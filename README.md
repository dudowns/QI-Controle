## 🎯 **Funcionalidades**

| Módulo | Recursos |
|--------|----------|
| 📊 **Dashboard** | Gráficos de receitas/despesas, gastos por categoria, evolução mensal |
| 💰 **Lançamentos** | Receitas e despesas com categorias, filtros por mês |
| 📅 **Contas do Mês** | Contas fixas, parcelamento, status de pagamento |
| 📈 **Investimentos** | Ações, FIIs, Cripto, Renda Fixa com cotação B3 |
| 🏦 **Renda Fixa** | CDB, LCI, Tesouro Direto com cálculo de IR/IOF |
| 💵 **Proventos** | Dividendos e JCP com notificações |
| 🎯 **Metas** | Acompanhamento com barra de progresso e depósitos |
| 👤 **Perfis** | Múltiplos usuários com avatar e PIN |
| ☁️ **Backup** | Exportação e restauração de dados |
| 🌐 **Sincronização** | Supabase Realtime |

## 🚀 **Como executar**

### Pré-requisitos
- Flutter 3.0+
- Dart 3.0+
- Git

```bash
# Clone o repositório
git clone https://github.com/dudowns/QI-Controle.git

# Entre na pasta
cd QI-Controle

# Instale as dependências
flutter pub get

# Execute
flutter run -d windows
